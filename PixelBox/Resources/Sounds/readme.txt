Sound files were MP3s converted to WAVs using Audacity.
The MP3 files can be found in the root directory inside .misc/

Optimal Audacity WAV export settings without inducing much loss in quality:
    Channel: Mono (Track splitted to mono prior to export)
    Sample Rate: 22050 Hz
    Encoding: Signed 16-bit PCM (.NET's SoundPlayer only accepts PCM encodings!)
